What it does

It runs a warm, unhurried interview.

AI-first · 8 phases

Research, Ideation, Design, Coding, Prototyping, Documentation, Management, Reflection — rated 0–4.

Human-first · 6 dimensions

Lived Experience, Local Knowledge, Relationship, Body, Risk, Judgment — what no model has.

What's new in this version

Multilingual. It detects your language.

Machine-readable output. It emits a JSON record:

Facilitator mode. Tell it you're running a workshop.

How to use it

  1. Download the .skill file and add it to Claude / Cowork.
  2. Describe a real, recent project — or just say "generate my CCL".
  3. Answer the questions honestly. There are no wrong answers.
  4. Get your two labels, the JSON block, and a link to the visual badge.
Level 0 always means “I believe I didn't use AI” — never a confession, never a judgment.
